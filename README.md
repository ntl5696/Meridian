# 🪶 Meridian

> Find your focus. Write without limits.

Modern writing tools have become bloated with complex menus and expensive subscription models. **Meridian** strips all of that away, giving writers a distraction-free writing environment paired with powerful manuscript compilation tools.

---

## 🌟 Key Features

- **🎧 Immersive Audio**: Block out distractions with ambient background soundscapes (rain, cafe) and tactile mechanical typewriter sounds.
- **🔥 Danger Mode**: An extreme anti-procrastination mode where text fades away if you stop typing for more than a few seconds.
- **📚 One-Click Manuscript Compiler**: Export full manuscripts to PDF, EPUB, Word (.docx), RTF, Markdown, and HTML with automatic chapter page breaks and customizable drop caps.
- **📊 Daily Streak Analytics**: Track your writing velocity (WPM), total words written, and session history on a visual heatmap calendar grid.
- **🔒 Local-First Privacy**: Your work belongs to you. No mandatory accounts or cloud lock-in—files are saved directly to your machine.

## 📥 Installation

### Windows
1. Download **`Meridian-Setup.exe`** from the [Latest Release](https://github.com/namle5696/meridian/releases/tag/v1.0.0).
2. Run the installer and launch Meridian.

### macOS
1. Download **`Meridian-Mac.dmg`** from the [Latest Release](https://github.com/namle5696/meridian/releases/tag/v1.0.0).
2. Open the `.dmg` file and drag **Meridian** to your Applications folder.
