Getting a "Dangerous file" or SmartScreen warning?

Because Meridian is a free open-source app and does not use a paid corporate certificate, Chrome & Windows SmartScreen may flag new .exe / .dmg downloads.

Chrome / Edge: Click ... next to file → Select Keep → Keep anyway.
Windows SmartScreen: Click More info → Click Run anyway.
macOS Gatekeeper: Right-click .dmg → Select Open → Click Open.
💡 Tip: Downloading the .zip version bypasses executable warnings!
